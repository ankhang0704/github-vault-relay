## 2. Core Safety Invariants & Verification

| Invariant | Implementation Mechanism | Automated Verification |
| :--- | :--- | :--- |
| **Zero Force-Push** | `updateBranchRef` enforces `force: false`. Throws error if `force: true` passed. | `PUSH-008`, `PUSH-022` |
| **Optimistic Concurrency** | Commit built with `parents: [baseCommitSha]`. Non-fast-forward updates abort immediately. | `PUSH-007` |
| **Atomic Single Commit** | All N eligible files combined into 1 Git tree and 1 commit. | `PUSH-006` |
| **No Silent Overwrite** | Only `LOCAL_ONLY` (CREATE) and `LOCAL_CHANGED` (UPDATE) are pushed. Conflicts blocked. | `PUSH-001`, `PUSH-002`, `PUSH-003` |
| **Deletion Deferred** | Local file deletion never triggers remote deletion. | `PUSH-004`, `PUSH-021` |
| **Post-Push Verification** | Re-fetches HEAD commit and tree from GitHub before updating `state.json`. | `PUSH-018`, `PUSH-019` |
| **25 MiB Size Ceiling** | Files $>25\text{ MiB}$ are skipped with warning to protect mobile memory. | `PUSH-009` |
| **Path Safety & Exclusions** | Excludes `.obsidian/`, `.git/`, `_fit/`, `_vault-relay/`, path traversal, and case collisions. | `PUSH-012`, `PUSH-013`, `PUSH-023` |
| **Offline Preflight** | Aborts immediately if device is offline without network timeouts. | `PUSH-014` |
| **Token Security** | Tokens stored only in Obsidian SecretStorage / device storage. Zero tokens in `data.json` or logs. | `tests/secretStore.test.ts`, `tests/redact.test.ts` |

## 3. Remote Write Surface Audit

Complete inventory of all mutating HTTP methods across the production codebase:

```text
POST /repos/{owner}/{repo}/git/blobs          -> GitHubClient.createBlob
POST /repos/{owner}/{repo}/git/trees          -> GitHubClient.createTree
POST /repos/{owner}/{repo}/git/commits        -> GitHubClient.createCommit
PATCH /repos/{owner}/{repo}/git/refs/heads/*   -> GitHubClient.updateBranchRef (force: false)
```

**Audited Absence**:
- Zero `DELETE` requests
- Zero `PUT /contents` requests
- Zero `force: true` parameters
- Zero branch deletion or ref destruction
- Zero native Git CLI or shell executions
